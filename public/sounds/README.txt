Put your own sound recordings in this folder to replace the built-in sounds.
Name each file after the sound it replaces, as .wav or .mp3:

  startup.wav    logging on (the Windows start-up sound)
  shutdown.wav   shutting down or restarting
  logoff.wav     logging off
  error.wav      error message boxes
  warning.wav    warning message boxes
  info.wav       information message boxes
  question.wav   question message boxes
  beep.wav       the BIOS power-on beep

Any sound without a file here uses the built-in synthesized version.
After adding or changing files, reload the page.
